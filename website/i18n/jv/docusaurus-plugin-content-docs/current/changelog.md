## Cathetan Owah-owahan

Kanggo riwayat lengkap lan rinci, waca
[CHANGELOG.md ing GitHub](https://github.com/bitranox/Thunderbird-Reply-with-Attachments/blob/master/CHANGELOG.md).

- 2.4.0: gambar wis ora dibuwang mung amarga pangirim masang `Content-ID` ing gambar kasebut; pilihan "Include inline pictures" wis dibusak, amarga Thunderbird dhewe wis nyimpen gambar sing ditempelake ing awak balesan; pranala saiki dibukak ing browser sistem; watesan 50 lampiran / 100 MB saben balesan, karo kabeh sing ora klebu dilaporake.
- 2.3.2: "Include inline pictures" nempelake gambar ing awak balesan minangka URI data base64 (dibusak maneh sawise tinjauan add-ons.thunderbird.net; Thunderbird nindakake iki dhewe); perbaikan kualitas kode lan perluasan cakupan tes.
- 2.3.1: Njaga lampiran sawisé Thunderbird ngasoaké kaca acara latar mburi; nambah hook debug sing ditargetaké kanggo ngatasi masalah.
- 2.3.0: Nglinuwihaké deduplikasi lampiran, ngluwihi cakupan tes, lan mbusak idin sing kadaluwarsa kanggo nyukupi kabijakan AMO.
- 2.1.0: Dhukungan internasionalisasi lengkap kanggo 100 basa paling ndhuwur
- 2.0.0: ditulis maneh dadi versi kanthi fitur lengkap (EN/DE)
- 1.0.1: diganti nganggo messages.listAttachments()
- 1.0.0: rilis pisanan
