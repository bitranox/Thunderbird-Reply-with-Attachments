## تبديلين جو لاگ

[GitHub تي CHANGELOG.md](https://github.com/bitranox/Thunderbird-Reply-with-Attachments/blob/master/CHANGELOG.md) ڏسو.

- 2.4.0: تصويرون هاڻي فقط ان ڪري نه ڇڏيون وينديون آهن جو موڪليندڙ انهن تي `Content-ID` رکيو هو؛ "Include inline pictures" اختيار ختم ڪيو ويو آهي، ڇاڪاڻ ته Thunderbird پاڻ شامل ٿيل تصويرن کي جواب جي مک متن ۾ رکي ٿو؛ لنڪ هاڻي سسٽم برائوزر ۾ کليون ٿا؛ هر جواب لاءِ 50 منسلڪات / 100 ايم بي جي حد، ۽ جيڪي به ڇڏي ڏنا وڃن ٿا انهن جي رپورٽ ڏني ويندي آهي.

- 2.3.0: اٽيچمينٽ ڊيوپليڪيٽ هٽائڻ ۾ سڌارو، ٽيسٽ ڪوريج ۾ واڌ، ۽ AMO پاليسين پوري ڪرڻ لاءِ متروڪ اجازتون هٽايون.
