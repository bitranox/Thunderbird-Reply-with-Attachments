## د بدلونونو تاریخچه

د بشپړ او مفصل تاریخ لپاره، د زېرمتون [CHANGELOG.md په GitHub کې](https://github.com/bitranox/Thunderbird-Reply-with-Attachments/blob/master/CHANGELOG.md) وګورئ.

- 2.4.0: انځورونه نور یوازې د دې لپاره نه غورځول کیږي چې لیږونکي پرې `Content-ID` ایښی وي؛ د "Include inline pictures" اختیار لرې شوی، ځکه چې Thunderbird پخپله ننوتلي انځورونه د ځواب په متن کې ساتي؛ لینکونه اوس د سیسټم براوزر کې خلاصیږي؛ د هر ځواب لپاره د 50 ضمیمو / 100 MB حد، او هر څه چې پریښودل شوي وي راپور ورکول کیږي.
- 2.3.2: "Include inline pictures" ننوتلي انځورونه د ځواب په متن کې د base64 ډیټا URI په توګه شاملول (د add-ons.thunderbird.net بیاکتنې وروسته بیا لرې شوی؛ Thunderbird دا پخپله کوي)؛ د کوډ کیفیت ښه توبونه او پراخ شوی ازموینې پوښښ.
- 2.3.1: ضمیمې ساتي حتی وروسته له هغه چې Thunderbird د شالید پېښو پاڼه بې‌کاره/غيرفعال کړي؛ د ستونزو د حل لپاره موخمن ډيبګ هوکونه زیاتوي.
- 2.3.0: د ضمیمو د نقل لرې کول لا ښه شوي، د ازموینو پوښښ پراخ شوی، او د AMO پالیسيو د پوره کولو لپاره زړې اجازې لرې شوې.
- 2.1.0: د ۱۰۰ مخکښو ژبو لپاره د نړیوالوالي بشپړ ملاتړ
- 2.0.0: بشپړ امکانات لرونکې نسخې ته له سره لیکنه (EN/DE)
- 1.0.1: messages.listAttachments() ته واوښتل
- 1.0.0: لومړنۍ خپرونه
